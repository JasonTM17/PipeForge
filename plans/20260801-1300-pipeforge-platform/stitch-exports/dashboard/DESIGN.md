# PipeForge Console Design System

Generated by Google Stitch for screen `15ba73c3a22b4e3aa4ff547c19bb7985`.

## Visual direction

- Dark graphite control-plane shell; no gradients or stock imagery.
- Dense but calm information hierarchy for experienced data engineers.
- Electric cyan is reserved for healthy/active state and primary actions.
- Amber is reserved for warnings and degraded processing state.
- Use thin restrained borders and square-to-low-radius surfaces; avoid card soup.

## Colors

- Background: `#0f1418`
- Lowest surface: `#0a0f13`
- Low surface: `#171c21`
- Main surface: `#1b2025`
- High surface: `#252b2f`
- Outline: `#3b494c`
- Primary cyan: `#00e5ff` / `#00daf3`
- Primary text: `#dee3e9`
- Muted text: `#bac9cc`
- Warning amber: `#feb300`

## Typography

- Inter for UI text: `text-sm`, `text-base`, `font-medium`, `font-bold`.
- JetBrains Mono for metrics, identifiers, timestamps, and throughput values.
- Uppercase compact labels for operational metrics; never use uppercase for long prose.

## Layout and components

- Collapsible 64px-to-240px left navigation with Overview, Datasets, Jobs, Quality Rules, Workers, and Artifacts.
- Fixed 64px top command bar with global search, workspace indicator, create-job action, notifications, and account menu.
- Four KPI panels above the active-job execution table.
- Dataset Health and System Activity panels below the job table.
- Tables and status chips must remain legible at narrow widths; use horizontal scrolling only as a last resort.
- Required states: loading skeleton, empty result, stale data, API error, forbidden, and retry action.

## Spacing

- Page gutter: `24px` desktop, `16px` tablet/mobile.
- Panel gap: `16px` to `24px`.
- Compact controls: `8px` to `12px` vertical rhythm.
